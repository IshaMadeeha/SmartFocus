# SmartFocus

A productivity and focus management application built with JavaScript, HTML, and CSS.

## 📋 Description

SmartFocus is a web-based tool designed to help users maintain focus, manage tasks, and boost productivity. With an intuitive interface and powerful features, SmartFocus provides an effective way to track progress and stay on top of your goals.

## 🛠️ Technologies

- **JavaScript** (52.7%) - Core application logic
- **HTML** (31.5%) - Markup and structure
- **CSS** (15.8%) - Styling and layout

## ✨ Features

- Task management and tracking
- Focus timer functionality
- Progress monitoring
- Clean and intuitive user interface
- Responsive design

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. Clone the repository:
```bash
git clone https://github.com/IshaMadeeha/SmartFocus.git
cd SmartFocus
```

2. Open the application in your browser:
```bash
open index.html
```
or simply double-click `index.html` in your file explorer.

## 💡 Usage

1. Open the application in your web browser
2. Create tasks or set focus goals
3. Use the built-in timer to maintain focus sessions
4. Track your progress and boost productivity
